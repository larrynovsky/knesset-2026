## 3. Explanation — что этот этап установил

### Прежняя сшивка голосований негодна, и масштаб больше, чем казался

Сшивка шла по совпадению названий и давала 212 голосований на 144 актах.
Заголовок голосования узнаётся в имени акта примерно у 10% записей.

Найден прямой типизированный ключ: **`KNS_PlmSessionItem`** (168 887 строк),
пункт повестки с `ItemTypeID=2` даёт `ItemID`, равный `BillID`. Из 7300 таких
пунктов 7299 есть в справочнике законопроектов (**P8 = 1.000**, ожидалось
≥0.95). Разбиение всех 7540 заголовков сходится без потерь:

```
4951  direct_bill_id · вне переписи
1805  direct_bill_id · в переписи
 457  нет пункта повестки
 327  non_bill_item
```

Прямой ключ даёт **1805 связей на 277 актах** вместо 212 на 144.

**Мост нашла вторая голова, не я.** Моя разведка 30.07 пробовала имя
`KNS_PlenumSessionItem`, получила HTTP-ошибку и записала «моста нет». Отказ
инструмента на угаданном имени был прочитан как факт о мире.

### Оговорки — несущий слой, а не шум. Я ошибался дважды

Из 1805 связей **1199 — голосования по оговоркам** (`הסתייгות N`), лежащие на
**30 актах** (топ-5 дают 46,1%, топ-10 — 71,9%; все 30 имеют третье чтение).

Я предлагал исключить их из направления. Вторая голова возразила: исключение
почти не меняет число покрытых законов, но стирает происходившее ВНУТРИ спорных
законов, а оговорка — преимущественно инструмент оппозиции; молчать про одну
сторону, сохранив другую, запрещает §7.

Я согласился, но предложил замер — вдруг оговорки не различают партии и
конвейер можно отложить. **Замер опроверг и это, в противоположную сторону:**

```
оговорки : медиана попарного согласия фракций 0.197
чтения   : медиана попарного согласия фракций 0.647
P11 · разница медиан: −0.450   (ожидалось ≥ +0.10)
```

Оговорки различают партии **втрое сильнее**, чем чтения. Дешёвого пути нет.

### Мост «голосующий → фракция» был неверен, исправление проверено

`PositionID=54` (`חבר/ת סיעה`, членство) — 191 запись; `FactionID ne null` —
217; разница 26 — `PositionID=48` (`יו"ר סיעה`, председательство). Код
фильтровал по `FactionID != null` и брал председательство как членство.

Проверено: записей 48 **без** парной записи 54 — **ноль**, фильтр ничего не
теряет. Касаний интервалов общей границей — **28** (большая гроздь на
2022-11-20), при `start <= d <= finish` это двойное членство и выбор по порядку
строк API.

Исправленный мост (только 54, ФИО решает, полуоткрытый интервал по полному
времени, **без запасного пути**) прогнан на **23 168** поимённых голосах:
**потеряно ноль** (P13, ожидалось <3%). Запасной путь, срабатывавший бы у 122
из 149 персон, не нужен вовсе.

**В код это ещё НЕ перенесено** — жило только в разведочном скрипте.

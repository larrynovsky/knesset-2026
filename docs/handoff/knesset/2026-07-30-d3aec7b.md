## 3. Explanation — решения и почему

**Решения владельца, зафиксированные в `criteria/keyvotes.yaml`:**

| правило | суть | коммит |
|---|---|---|
| K6 | пункт чек-листа задаётся нормой, а не законопроектом | `13f743f` |
| K7 | прочерк вне шкалы: 0 = «баланс не меняется», null = «не смог решить» | `656a34f` |
| `stopping_rule` | порог 85% по общему знаку; ниже — **эскалация к владельцу**, не автоправка; мораторий на правки кодбука | `2b63578` |
| K2d v2 | основание **вычисляется** из разложения, не заявляется моделью | `d4122f4` |

**Мораторий разморожен один раз**, повод назван блокирующим: K2d в прежнем виде
отверг 48 ответов из 112, и отверг **не случайно** — у всех отклонённых знак ≠ 0
(28 минусов, 20 плюсов, ни одного нуля). Выборка сместилась к нулям, согласие
считалось на 23 актах вместо 54. Это не «расхождение неудобно», это карточка
не строится.

**Тупик, в который не надо возвращаться: порог contrast.** Искали величину,
которой в мировой практике нет. Comparative Agendas Project кодирует по
«единственной преобладающей области» — суждение, механическое правило только
для ничьей. Krutz (2001) меряет омнибус числом тем и абсолютным размером, сам
называя пороги произвольными. Court-curbing литература (Catalano), откуда взят
наш чек-лист, главную норму не выбирает вовсе. Отсутствие порога в кодбуке было
не упущением автора.

**Отвергнуто и почему:**
- *вторичный источник соглашений (IDI)* — первичный оказался доступен через
  браузер; вторичный годился бы только при недоступности всех восьми файлов;
- *`tesseract --user-words`* — проверен, LSTM-движок игнорирует, ноль изменений;
- *позиционное правило для гершаим* — испортило бы `מתחייב` («обязуется»),
  слово из каждого обязательства;
- *OCR в Cowork-контейнере* — §14: контейнер эфемерен, текст цитат
  не воспроизводился бы.

**Мины:**
- `ssh` без login-шелла **не видит Homebrew**. Четыре ложных вывода начались
  с этого. Всегда `export PATH=/opt/homebrew/bin:$PATH`.
- Гейт §9 ловит имя легаси-эндпоинта **в комментариях**. Не обходить —
  переписать текст.
- Гейт ponytail требует `loc` с точностью 20% и резолвимые `ref:` — путь вне
  репозитория не резолвится.
- Не запускать два прогона одновременно на одном кэше (правило из пилота kegan).

**Отложенное словами владельца:** «Форма K2d — вычисляемое поле», «мораторий
принимаю», «партию выбери сам», «Критерий остановки и эскалации 85% ок».

## 5. Остаточная неопределённость

- **Прокси «цитата overall = цитата одной нормы» не проверен глазами.**
  У 31 из 48 отклонённых совпадение дословное, но совпадение цитат может не
  означать «знак дан по этой норме». От этого зависит, годится ли механическая
  проверка K2d в любом виде. Десять обоснований, глазами, час.
- **Девять расхождений вендоров по общему знаку не разобраны.**
  `stopping_rule` предписывает при недоборе порога разбор конкретных случаев,
  а не число. Не сделано.
- **R7: согласие по разложению 14,8%.** Публикуем разложение, а сверка
  подтверждает только вердикт. В проекте перевода тот же класс решён union'ом
  находок с калибровкой многословного вендора — у нас пересечение. Решение
  не принято.
- **Промпт писала Anthropic, она же оценщик.** Правило из SKILL.md книжного
  конвейера прямо запрещает такую конфигурацию. Владелец разрешил переписать
  промпт третьей моделью — не сделано.
- Сшивка голосований с биллями **17%** (119 из 691). Для скелета хватило,
  для корпуса нет.
- Гершаим: осталось `שייח` — 2, `יוייר` — 6. Мелочь, но не ноль.

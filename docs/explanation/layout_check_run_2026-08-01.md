# Прогон `check_layout.py`: где он выполнялся и почему не на MacBook

Акт приёмки `plans/ACCEPTANCE_mockup_v5_2026-08-01.md` утверждает: «8 × 6 = 48
проверок, прокрутки нет нигде». Второй проверяющий 01.08.2026 это утверждение
**не смог воспроизвести** и сказал об этом прямо:

```
python3 scripts/check_layout.py design/mockup_v5
ModuleNotFoundError: No module named 'playwright'
```

Playwright на MacBook нет — ни в системном python3, ни в brew-питоне, ни в
пользовательских каталогах, ни в `~/Library/Caches/ms-playwright`. То есть на
**единственной пишущей машине** (§19) пятнадцатая проверка не запускается, и
строка акта была утверждением, а не механизмом.

## Что сделано

Прогон выполнен в изолированной среде агента, где Chromium и Playwright
предустановлены. Восемь страниц макета скопированы туда как есть.

```
ЗЕЛЁНЫЙ: 8 страниц × 6 ширин = 48 проверок, прокрутки нет нигде
```

Утверждение акта **подтверждено**.

## Проверка сломана нарочно

Зелёный прогон сам по себе не доказывает, что проверка работает. В копию
`index.html` перед `</body>` вставлен элемент шире вьюпорта:

```html
<div style="width:2000px;height:4px"></div>
```

Результат — красное на шести ширинах из шести, с указанием виновника:

```
КРАСНЫЙ  index.html   768px: scrollWidth 2018 > clientWidth 768
           виновник: DIV → 2018px
ГОРИЗОНТАЛЬНАЯ ПРОКРУТКА ЕСТЬ — 6 случаев
```

Проверка настоящая: краснеет и называет элемент, а не только факт.

## Что остаётся дырой

**Прогон невоспроизводим на машине проекта.** Он состоялся в чужой среде и на
копии файлов; из чистого клона на MacBook команда по-прежнему падает импортом.
Это нарушает §14 (всё публикуемое воспроизводимо из репозитория) и оставляет
§21 без работающего механизма там, где работа реально идёт.

Закрывается одним из двух, и выбор за владельцем:

1. `pip install playwright --break-system-packages && playwright install chromium`
   на MacBook, плюс цель в `Makefile` (её сейчас тоже нет, хотя бриф требует);
2. объявить проверку внешней и записать в §21, что она гоняется вне машины
   проекта — тогда она перестаёт быть частью воспроизводимой сборки, и это
   надо сказать вслух, а не оставить умолчанием.

До выбора честная формулировка такая: **вёрстка проверена один раз 01.08.2026 в
чужой среде; на машине проекта проверки нет.**

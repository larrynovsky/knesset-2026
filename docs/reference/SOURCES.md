### ⚠️ Запрещённый эндпоинт (CLAUDE.md §9)

`https://knesset.gov.il/Odata/Votes.svc` — отвечает **HTTP 200** и отдаёт **ноль** записей для 25-го Кнессета. Обрыв на 13.07.2021. Без ошибки. Проверено: `vote_rslts_kmmbr_shadow/$count?$filter=knesset_num eq 25` → 0.

Через него построена значительная часть публичных туториалов и обёрток. Зеркала Open Knesset `mk_voted_against_majority` и `mk_party_discipline_stats` обновляются по дате, но данные внутри заканчиваются 13.07.2021 — файл свежий, содержимое мёртвое.

### Ловушки

1. `ForOptionDesc` / `AgainstOptionDesc` определяют, **что означает «за»** в конкретном голосовании: принять · передать в комитет · отклонить. Без них голоса не интерпретируются (§10).
2. Кнессет **объединяет 2-е и 3-е чтения** в одно голосование.
3. **Три несовпадающих пространства ID персон**: `KNS_Person.Id` · vip_id (в `KNS_PlenumVoteResult.MkId`) · site id. Моста `Person.Id ↔ vip_id` в API **нет** — «как голосовал» и «что вносил» напрямую не соединяются. Мост vip_id ↔ site id даёт `KNS_MkSiteCode`. Проверено на двух персонах, не на всех 120.
4. HTML-страницы (`main.knesset.gov.il/*.aspx`) закрыты ботозащитой Reblaze — 247/474 неброузерным клиентам. API и статические PDF открыты.

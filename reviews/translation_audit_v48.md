## Выборка и границы

Из всех `site/l-*.html` и `site/f-*.html` взяты элементы списков примеров `<li><bdi>…</bdi></li>`, сопоставленные с `names[id].ru`: 33 уникальных названия / 33 ID. Добавлены четыре ID владельца из ссылок `grounds.html#a…`. Случайные 30 получены строго из всех 292 ключей справочника: `random.Random(20261019).sample(sorted(names, key=int), 30)`. Порядок популяции определён числовым ID; seed без определения порядка недостаточен. Четыре случайных ID пересекаются с примерами: 33 + 4 + 30 − 4 = 63.

Коллизия: «Основной закон: изучение Торы» есть у 2198907 и 2208935. В примерах участвует 2198907: он есть в `criteria/theme_signs_religion_state.json` и `votes_25.json`; `theme_arrows.py` строит примеры только из строк голосований с тематическими знаками. 2208935 в голосованиях отсутствует и в выборку не включён. Название 2198907 в исходном срезе начинается с חוק-יסוד, поэтому отсутствие слова «проект» у него ошибкой перевода не признано. Юридический статус принятия этим аудитом не устанавливается.

Для 62 ID прочитаны полные `bill_name` из `data/votes_25.json`; все их варианты по одному ID совпадают, `he_head` соответствует началу полного названия. Для случайного 2237942 строк в голосованиях нет: полное название взято из `data/bills_scan.json`, поле `matched[].name`, с проверкой `he_head`. Оно соответствует текущему русскому переводу; это единственное отступление от основного источника.

Проверены предмет, объект, обозначение проекта/закона по оригиналу, временный характер, номера поправок и существенные уточнения. Ошибок в номерах поправок и пропуска «временного предписания» в этой выборке не обнаружено. Различия стиля, транслитерации, регистра, «харедим / ультраортодоксы» не правились. Пропуск еврейского года разрешён конвенцией справочника. Текущий статус закона и точность самой выгрузки не проверялись.
